## [0.1.0] - 2026-08-20

### Added

- Self-hosted FastAPI/PostgreSQL implementation with Alembic migrations.
- Strict route graph validation, derived paths/friction/fingerprints, and state-aware ETags.
- Editorial verification/publication/supersession/staleness/withdrawal workflow.
- Scoped API-key lifecycle, database quotas, observation idempotency, and audit events.
- Transactional, signed, SSRF-resistant webhook delivery worker.
- Daily challenge projection, Docker Compose quickstart, generated OpenAPI contracts,
  pinned CI, CodeQL, dependency review, and operator/security documentation.
